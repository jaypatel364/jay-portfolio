# PWA Icons

Replace `icon-192.png` and `icon-512.png` with properly designed icons before deploying.

## Recommended approach

1. Design a square icon (your logo / initials) at 512×512px
2. Export as PNG
3. Use https://www.pwabuilder.com/imageGenerator to generate all sizes from the 512px source
4. Replace the placeholder files in this folder

## Required sizes

- `icon-192.png` — 192×192px (maskable, used on Android home screen)
- `icon-512.png` — 512×512px (used for splash screen and app install)
